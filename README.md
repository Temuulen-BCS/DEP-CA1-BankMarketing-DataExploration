# Bank Marketing Data Analysis CA1

The dataset that will be used for this project is UCI Machine Learning Repository - Bank Marketing. Here is the link:

https://archive.ics.uci.edu/dataset/222/bank+marketing

I will be focusing on the problem of identifying which customer characteristics are associated with successful bank term-deposit subscriptions.

I will be using R programming language with RStudio, along with Git and GitHub tools for this project.
